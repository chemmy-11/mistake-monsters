# v1.0.0 首发版

「错题小怪兽」小学数学 AI 错题本，首个正式版本。

## 功能

- 📸 拍照 / 相册收录错题：视觉大模型只转录题目与学生的错误答案，**不直接解题**
- 🧠 错因归纳：9 条预置错因库自动匹配，附辅导策略
- 💾 长期记忆：错因模式自动沉淀 + 家长观察，汇总为「AI 学生画像」注入全部 AI 环节（每 8 题刷新）
- 📝 同类题练习卷：按错题/错因出题（含变式），出题后 AI 自校验修正答案
- 📄 PDF 导出：A4 练习卷（题目+答题框）+ 参考答案页，保存到系统下载目录
- 🧙 AI 小老师：引导式订正、铁律不给答案；三级提示链；解析门
- 🔄 在线更新：启动自动检查新版本，应用内下载并引导安装
- 🈳 演示模式：不配置 Key 也能离线体验全流程

## AI 配置

默认预设智谱 GLM，支持任意 OpenAI 兼容接口（阿里百炼 / DeepSeek / OpenAI / 硅基流动 / Kimi），视觉与文本模型分开配置，密钥只存本机。

## 安装说明

下载下方 APK 安装。若系统提示「禁止安装未知应用」，按引导授权本应用后重试。
