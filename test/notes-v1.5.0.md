# v1.5.0 · 新增「思考深度」设置 + 输出预算放宽到服务商上限

- ✨ **新增「思考深度」**（设置 → AI 服务商 → 思考深度）：以 `reasoning_effort` 下发给推理模型，可选 低 / 中 / 高 / **默认「高」**。档位越高，模型思考越充分、越不容易算错，代价是更慢。推理模型（如 deepseek-flash）支持；非推理模型会忽略该参数
- ⬆️ **输出预算放宽到服务商上限**（DeepSeek 为 **393216 tokens**，即 38 万；此前只有 2000-6000）。`max_tokens` 只是上限、按实际生成量计费，所以放宽不额外花钱，但能彻底避免"思维链把预算吃光导致答案为空"的问题
- 🛡 **服务商不支持时自动降级重试**：若某个服务商拒绝大 `max_tokens` 或 `reasoning_effort`（如 OpenAI gpt-4o 系上限 16384），应用会自动去掉该参数、降到保守预算重试一次，不影响"任意 OpenAI 兼容接口"的兼容性
- 🔧 修复切换服务商预置时可能丢失"演示模式"开关状态的问题（内部字段顺序调整引发的参数错位）

> 从 v1.3.0 升级：应用内点「检查更新」或下载本页 APK 覆盖安装（签名一致，数据保留）。v1.4.0 已修复的「分析卡住」与新增的「我认为的错因」也包含在内。
