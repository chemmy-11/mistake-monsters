# v1.4.0 · 修复「AI 分析并归纳」卡住 + 新增「我认为的错因」

- 🐛 **修复「AI 分析错因并收录」卡住/失败**。根因：默认模型 `deepseek-flash` 属于**推理模型**，输出前先产出思维链，而**思维链与答案共享 `max_tokens` 输出预算**——原预算（分析 2000 / 错因画像 800 / 小老师 300）被推理过程吃光，导致答案被截断甚至为空，界面一直停在"分析中"。现已按推理模型特性把各环节预算调足：识别 4000、错因分析 6000、同类题 6000、自校验 6000、学生画像 3000、小老师 2000
- 🛡 若仍被截断，会直接提示原因并指引到设置更换模型（不再静默重试浪费时间）；分析步骤另加 **150 秒超时保护**，超时回到可重试状态，不会再卡死
- ✨ **新增「我认为的错因（可不填）」**：复核页在「我的答案」下方新增一行，学生自己的判断会作为线索注入分析提示词，帮助 AI 更准地归因（AI 仍独立核对题目与答案，不盲从自评）
- ✅ 真实 DeepSeek Key 实测：拍照识别 ✓、错因分析 5 秒 ✓、同类题生成 13.6 秒 ✓、AI 小老师 1.8 秒 ✓、学生画像 8.7 秒 ✓
